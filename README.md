# World Economy Quiz — Telegram Mini App

Квиз для подготовки к устному экзамену по мировой экономике. 13 уровней-тем (316 вопросов), финальный экзамен, работа над ошибками и тренировка устного ответа по 110 экзаменационным вопросам. Работает внутри Telegram (Mini App) и в обычном браузере; прогресс синхронизируется между устройствами через Telegram CloudStorage.

Вопросы — на английском (экзамен на английском), интерфейс — русский, украинский или английский.

## Запуск

Нужен Node.js 20+ (проверено на 22).

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты движка и хранилища (Vitest)
npm run build      # проверка TypeScript + сборка в dist/
npm run preview    # посмотреть собранную версию
```

Вне Telegram приложение работает полностью: прогресс хранится в `localStorage`, кнопка «Назад» рисуется в шапке.

## Структура

```
content/              исходники вопросов (их и редактируем) и скрипт сборки банка
public/data/questions.json   банк, который грузит приложение (собирается из content/)
src/engine/           чистая логика: перемешивание, проверка ответов, жизни, финал, ошибки, валидация банка + тесты
src/storage/          схема прогресса progress_v1, миграции, адаптер CloudStorage/localStorage + тест
src/telegram/         обёртка над Telegram.WebApp с заглушками вне Telegram
src/i18n/             строки интерфейса (ru / uk / en)
src/ui/               экраны, иконки-дудлы, стили
src/config.ts         чат для сообщений об ошибках и ссылка на репозиторий
```

## Как добавить или исправить вопрос

1. Откройте нужный файл в `content/src/` (`bank_part1.md` — уровни 1–5, `bank_part2.md` — 6–9, `bank_part3.md` — 10–13; тезисы для устного экзамена — `exam_points.md`). Формат:

   ```
   ### single | 32 | 2 | v          тип | номера экз. вопросов | сложность 1–3 | v = цифры устаревают
   Q: Текст вопроса
   * правильный вариант             (single: ровно 1; multi: 2–4 из 5)
   - неправильный вариант
   E: Объяснение, которое видно после ответа
   ```

   Для `order` вместо `*`/`-` пишутся пункты `1. … 2. …` **в правильном порядке** (3–6 штук).

2. Соберите банк (нужен Python 3.10+):

   ```bash
   npm run content:build
   ```

   Скрипт проверит исходники (число вариантов, правильных ответов, покрытие экзаменационных вопросов, дубли) и при ошибке покажет файл и строку. При успехе он обновит `public/data/questions.json` и `questions_preview.md` (все вопросы с отмеченными ответами — удобно показать преподавателю).

3. Закоммитьте и запушьте — сайт обновится сам.

> ID вопросов (`L05-012`) вычисляются по порядку внутри уровня. Если вставить вопрос в середину уровня, ID следующих сдвинутся, и их счётчики в «работе над ошибками» у игроков перепутаются. Новые вопросы лучше добавлять в конец уровня.

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub (например `econ-quiz`) и запушьте туда проект:
   ```bash
   git init
   git add .
   git commit -m "World Economy Quiz"
   git branch -M main
   git remote add origin https://github.com/<ваш-ник>/econ-quiz.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` запускается при каждом пуше в `main`: ставит зависимости, гоняет тесты, собирает и публикует. Через 1–2 минуты сайт будет по адресу `https://<ваш-ник>.github.io/econ-quiz/` (ссылка видна во вкладке **Actions** → последний запуск → `deploy`).
4. Поправьте `src/config.ts`: `REPO_URL` — ссылка на ваш репозиторий, `REPORT_CHAT` — ник чата или канала (без `@`), куда игроки будут присылать ошибки в вопросах.

`vite.config.ts` использует `base: './'` (относительные пути): в приложении нет URL-маршрутов, поэтому оно работает под любым именем репозитория, и `base` не нужно менять при переименовании.

## Привязка к Telegram-боту

1. **Создать бота.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и ник (должен заканчиваться на `bot`, например `econ_quiz_bot`). Токен сохраните в секрете; для этого приложения он не нужен, свой серверный код боту не требуется.
2. **Задеплоить сайт** (раздел выше) и скопировать HTTPS-адрес `https://<ваш-ник>.github.io/econ-quiz/`.
3. **Привязать Mini App** — любой из способов (можно оба):
   - `/newapp` в BotFather → выберите бота → название, описание, картинка 640×360 → **Web App URL** = адрес сайта → короткое имя (например `quiz`). Получится ссылка `https://t.me/econ_quiz_bot/quiz`, которая открывает приложение сразу.
   - Кнопка меню: `/mybots` → ваш бот → **Bot Settings → Menu Button** → отправьте адрес сайта и подпись кнопки (например «Квиз»). Кнопка появится слева от поля ввода в чате с ботом.
4. **Поделиться с одногруппниками.** Отправьте ссылку `https://t.me/<бот>/<короткое имя>` в чат группы или закрепите её. Прогресс у каждого свой: он привязан к Telegram-аккаунту и одинаков на телефоне и компьютере.

## Технические заметки и отличия от ТЗ

- **CloudStorage**: значения ограничены 4096 символами, поэтому прогресс (JSON) режется на куски `progress_v1_0…N`, а в ключе `progress_v1` лежит их количество. Запись в облако идёт с задержкой 1,5 с и сразу при сворачивании приложения. Локальная копия в `localStorage` пишется всегда. При запуске берётся более свежая копия (по `savedAt`), так что прерванная запись или сбой облака не теряют прогресс.
- **Версии Telegram**: каждое API включается только если клиент его поддерживает (`isVersionAtLeast`): `BackButton`/`HapticFeedback`/`setBackgroundColor` — 6.1, `showConfirm` — 6.2, `CloudStorage` и HEX-цвет в `setHeaderColor` — 6.9, `disableVerticalSwipes` — 7.7. На старых клиентах — кнопка «Назад» в шапке, `window.confirm` и `localStorage`.
- **Тема**: светлая/тёмная выбирается по `colorScheme` Telegram (и событию `themeChanged`), вне Telegram — по `prefers-color-scheme`. Цвета берутся из собственной «бумажной» палитры, а не из `themeParams`, чтобы сохранить стиль. Шапку и фон Telegram красим в цвет бумаги через `setHeaderColor`/`setBackgroundColor`. Весь текст контрастнее WCAG AA (≥ 4,5:1) в обеих темах.
- **Рисованный стиль**: контуры карточек и кнопок «дрожат» за счёт SVG-фильтра (`feTurbulence` + `feDisplacementMap`), наложенного только на псевдоэлемент с рамкой, поэтому текст остаётся чётким. Если фильтр не поддерживается, остаются неровные `border-radius`.
- **Язык**: в Telegram — по `language_code` (`uk` → украинский, `ru` → русский, остальное → английский); если кода нет — русский. В обычном браузере то же правило применяется к языку браузера.
- **`python3`**: на Windows команда `python3` часто оказывается заглушкой Microsoft Store, поэтому `npm run content:build` пробует `python3`, затем `python` и `py`. В `build_bank.py` добавлен `newline="\n"`, чтобы на Windows файлы не менялись из-за CRLF. Содержание вопросов не тронуто, сборка даёт байт-в-байт тот же `questions.json`.
- **`data/questions.json`** — исходная копия банка из постановки. Приложение использует `public/data/questions.json` (идентичный файл). Папку `data/` можно удалить, чтобы не держать две копии.
- **Сообщить об ошибке**: шаблон с ID вопроса копируется в буфер, затем через `openTelegramLink` открывается `t.me/<REPORT_CHAT>`. Если буфер обмена недоступен, игрок увидит подсказку указать ID вопроса вручную.

## Вопросы к контенту

Автоматические проверки банка ничего не нашли: сборка из `content/src` проходит без ошибок и совпадает с присланным `questions.json`. Все 110 экзаменационных вопросов покрыты квизом, ссылки `quizQuestionIds` верны. В multi-вопросах формулировка не выдаёт число правильных ответов, правильный вариант не выделяется длиной, позиции правильных ответов распределены ровно. Фактическую проверку всех 316 вопросов я не проводил.

Замечания, которые стоит посмотреть человеку:

- Во всех 40 multi-вопросах в тексте уже есть «Select all that apply.», и интерфейс показывает ту же подсказку («Выберите все подходящие»). Не ошибка, но можно убрать фразу из текста вопросов.
- 55 вопросов помечены `v` (цифры 2025 года: ВВП, торговля, рейтинги). Их нужно обновлять раз в год, а заодно поле `dataAsOf` в `build_bank.py`.
