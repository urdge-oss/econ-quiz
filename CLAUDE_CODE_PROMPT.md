# Задача: Telegram Mini App «World Economy Quiz»

Сделай мини-игру-квиз для подготовки к устному экзамену по мировой экономике. Она открывается внутри Telegram через бота (Telegram Mini App), работает на телефоне и компьютере, прогресс синхронизируется между устройствами. Квиз должен быть непростым, но обучающим: после каждого ответа, правильного или нет, игрок видит объяснение.

Сначала прочитай этот файл целиком и `data/questions.json`, затем предложи короткий план (структура проекта, этапы) и после этого реализуй. Если какое-то требование противоречит актуальной документации Telegram Mini Apps, сверься с https://core.telegram.org/bots/webapps и выбери рабочий вариант, отметив это в README.

### Схема `questions.json`

```jsonc
{
  "schemaVersion": 1,
  "dataAsOf": "2026-11",
  "language": "en",                      // язык вопросов (экзамен на английском)
  "levels": [{
    "id": 1, "slug": "basics",
    "title": "The Big Picture",          // игровое название уровня
    "subtitle": "World economy: concept, history, structure, country groups",
    "examRange": [1, 5],                 // какие экзаменационные вопросы покрывает
    "briefing": ["...", "..."]           // 5–6 ключевых фактов, показываются перед уровнем
  }],
  "finalExam": { "title": "Final Exam", "subtitle": "...", "questionsPerLevel": 3 },
  "questions": [{
    "id": "L05-012",
    "level": 5,
    "type": "single" | "multi" | "order",
    "examRefs": [32],                    // номера экзаменационных вопросов
    "difficulty": 1 | 2 | 3,
    "volatile": true,                    // содержит цифры, которые устаревают (обновлять раз в год)
    "question": "...",
    "options": [{ "id": "a", "text": "..." }],   // хранятся уже перемешанными
    "correct": ["c"],                    // single: 1 id; multi: 2–4 id; order: все id в правильном порядке
    "explanation": "..."                 // показывается после КАЖДОГО ответа
  }],
  "examQuestions": [{
    "n": 41,
    "title": "Ownership advantages (OLI)",          // исправленная формулировка
    "originalTitle": "Advantages of property.",      // как в силлабусе
    "level": 6,
    "keyPoints": ["...", "..."],                     // 3–4 тезиса для устного ответа
    "quizQuestionIds": ["L06-009", "L06-010"]
  }]
}
```

Типы вопросов: `single` — 4 варианта, один правильный; `multi` — 5 вариантов, от 2 до 4 правильных (количество правильных игроку не показывать); `order` — 3–6 пунктов, которые нужно расставить по порядку.

## 2. Технологии и архитектура

- **Фронтенд:** Vite + React + TypeScript (strict). Статическое SPA, без своего бэкенда в первой версии.
- **Telegram:** подключи `https://telegram.org/js/telegram-web-app.js`. Используй `Telegram.WebApp`: `ready()`, `expand()`, `disableVerticalSwipes()` (если доступно — проверяй через `isVersionAtLeast`), `BackButton` для навигации назад, `HapticFeedback` (успех/ошибка/выбор), `themeParams` и `colorScheme` для светлой/тёмной темы, `setHeaderColor` / `setBackgroundColor` под цвет приложения.
- **Хранение прогресса:** `Telegram.WebApp.CloudStorage` — он привязан к пользователю и синхронизируется между устройствами. Учитывай лимиты на размер значения и число ключей: храни компактно, пиши с debounce. Вне Telegram (обычный браузер при разработке) — fallback на `localStorage`. Все обращения к хранилищу — через один модуль-адаптер.
- **Приложение должно полностью работать в обычном браузере** (без Telegram) — для разработки и для тех, кто откроет ссылку напрямую.
- **Хостинг:** GitHub Pages, деплой через GitHub Actions при пуше в `main`. Учти `base` в `vite.config` для пути репозитория.
- **Данные:** `questions.json` лежит в `public/data/`, грузится при старте; при загрузке — валидация структуры (zod или ручные проверки). Если данные битые — понятный экран ошибки, а не белый экран.
- **Контент-пайплайн:** добавь npm-скрипт `content:build`, который запускает `python3 content/tools/build_bank.py` и копирует результат в `public/data/questions.json`. В README опиши, как добавить или исправить вопрос.

### Структура кода

- `src/engine/` — чистая игровая логика без React: перемешивание (Fisher–Yates), проверка ответов всех трёх типов, жизни, конец игры, сборка финального теста, логика «работы над ошибками». Покрой её юнит-тестами (Vitest).
- `src/storage/` — адаптер CloudStorage/localStorage, схема прогресса с версией (`progress_v1`), миграции.
- `src/telegram/` — обёртка над `Telegram.WebApp` с безопасными заглушками вне Telegram.
- `src/ui/` — экраны и компоненты.
- `src/i18n/` — строки интерфейса.

## 3. Игровая механика

### Уровни
13 уровней-тем из `levels` (каждый покрывает свой блок экзаменационных вопросов) + **Финальный экзамен** по всем темам. Все уровни открыты сразу: игрок сам решает, когда готов к финалу. На кнопке финала можно мягко подсказать «рекомендуем после всех уровней», но не блокировать.

Перед стартом уровня — экран **брифинга**: название, подтема, «Exam questions 38–48», 5–6 ключевых фактов из `briefing`, выбор режима и кнопка «Начать».

### Режимы
- **Обычный:** 3 жизни.
- **Хардкор:** 1 жизнь.

Неправильный ответ отнимает жизнь. Когда жизни закончились — экран «Game over»: сколько вопросов пройдено, на каком вопросе ошибся, правильный ответ и объяснение, кнопка «Заново». Повторный запуск всегда **заново перемешивает и порядок вопросов, и порядок вариантов ответа**. Уровень пройден, если игрок ответил на все вопросы уровня и у него осталась хотя бы одна жизнь.

### Перемешивание
- Порядок вопросов: случайный при каждом запуске.
- Варианты `single`/`multi`: случайный порядок при каждом показе. Буквы A/B/C/D на кнопках — по позиции на экране, а не по `id`.
- `order`: перемешай пункты и убедись, что стартовая раскладка не совпадает с правильной.

### Как отвечать
- **single:** нажатие на вариант = ответ (с короткой анимацией выбора).
- **multi:** игрок отмечает варианты, затем жмёт «Проверить». Подсказка: «Выберите все подходящие». Ответ верен, только если выбранное множество точно совпадает с правильным.
- **order:** игрок нажимает пункты по очереди, и они выстраиваются в список (drag-and-drop — по желанию, но тап-режим обязателен: на телефоне он надёжнее). Можно убрать пункт обратно. Кнопка «Проверить». Верно, только если все позиции правильные; при ошибке показать правильный порядок и отметить, какие позиции совпали.

### Обратная связь после каждого ответа (это главное для обучения)
- Подсветить правильный вариант и выбранный неправильный (цвет + иконка ✓/✗, не только цвет).
- Показать `explanation`.
- Бейдж «📖 Exam Q32 — Global financial market…» с названием экзаменационного вопроса (берётся из `examQuestions`).
- Для `volatile` — маленькая метка «🔄 данные на 2026».
- Кнопки: «Дальше» и маленькая «Сообщить об ошибке в вопросе» (копирует в буфер шаблон с id вопроса и открывает чат из конфига через `openTelegramLink`; ник чата — константа в `src/config.ts`).
- При ошибке — анимация «трескающегося» сердечка и `HapticFeedback.notificationOccurred('error')`; при верном ответе — `'success'`.

### Результаты и прогресс
- Звёзды за уровень в обычном режиме: прошёл с 3 жизнями → ★★★, с 2 → ★★, с 1 → ★. Прохождение в хардкоре — отдельный значок (например, нарисованная корона).
- Сохраняется лучший результат по каждому уровню и режиму, общая точность, лучшая серия правильных ответов подряд.
- На главном экране — общий прогресс: сколько уровней пройдено и сколько звёзд собрано.
- Во время игры: номер вопроса из общего числа («12 / 26»), жизни (нарисованные сердечки), текущая серия.

### Финальный экзамен
- Собирается заново при каждом запуске: по `finalExam.questionsPerLevel` (по умолчанию 3) случайных вопроса из каждого уровня, итого 39. Внутри уровня старайся брать разную сложность. Затем всё перемешивается.
- Те же правила жизней (обычный / хардкор).
- Экран результата финала: разбивка по темам («Money Matters: 2/3»), чтобы было видно, какие темы подтянуть, и кнопки «Повторить уровень X».

### Работа над ошибками
- Каждый неправильный ответ добавляет вопрос в список ошибок.
- Отдельный режим без жизней: прогоняет вопросы из этого списка в случайном порядке. Вопрос удаляется из списка после двух правильных ответов подряд в этом режиме.
- На главном экране — счётчик «Ошибок к повторению: N».

### Устный экзамен (тренировка ответа вслух)
Экзамен устный, поэтому нужен режим, который тренирует именно это:
1. Показать случайный экзаменационный вопрос (`examQuestions[].title`, мелко — `originalTitle`).
2. Таймер на 2 минуты (настраивается: 1 / 2 / 3 минуты). Игрок отвечает вслух.
3. Кнопка «Показать тезисы» → список `keyPoints` с чекбоксами. Игрок отмечает, что успел сказать.
4. Самооценка сохраняется (сколько тезисов из скольких). Кнопка «Потренировать вопросы по теме» запускает мини-квиз без жизней из `quizQuestionIds`.
5. Фильтр «Только из уровня…» и «Сначала те, где оценка ниже».

## 4. Визуальный стиль

Лёгкий рисованный стиль, как будто на бумаге в тетради: спокойные приглушённые цвета, ничего яркого и кричащего, чтобы не отвлекать от вопросов.

- **Фон:** тёплая бумага (например `#F4EFE6`) с очень лёгкой текстурой или клеточкой; тёмная тема — «грифельная доска» (например `#2B2E2A`), включается по `colorScheme` из Telegram.
- **Текст:** тёмный «чернильный» (`#2F2B27`); в тёмной теме — «мел» (`#E8E4DA`).
- **Акценты:** приглушённые. Верно — шалфейный зелёный (`#7C9A7E`), неверно — кирпичный (`#B9705F`), выделение — выцветший синий (`#6F86A6`) или охра (`#C9A55C`). Подбери итоговую палитру сам, но с контрастом текста не ниже WCAG AA.
- **Формы:** кнопки и карточки с «неровными» рисованными контурами — через rough.js или SVG-фильтр (`feTurbulence` + `feDisplacementMap`), лёгкая тень «от карандаша». Контуры не должны мешать читать текст.
- **Шрифты:** рукописный только для заголовков, номеров уровней и счётчиков (с поддержкой кириллицы, например Caveat или Neucha). Текст вопросов и ответов — спокойный читаемый шрифт (например Nunito). Подключи через `@fontsource` (локально), без внешних CDN.
- **Иконки:** свои простые дудл-SVG (сердечко-жизнь, звезда, корона, книжка, таймер, карандаш), без чужих брендов и персонажей.
- **Анимации:** короткие и мягкие (200–300 мс); учитывай `prefers-reduced-motion`.
- **Мобильная вёрстка в первую очередь:** ширина от 320 px, кнопки ответов на всю ширину, область нажатия не меньше 44 px, учёт safe-area. Длинные варианты ответов переносятся, ничего не обрезается.

## 5. Язык интерфейса

Вопросы, ответы и объяснения — на английском (экзамен на английском). Интерфейс — на русском по умолчанию, плюс украинский и английский. Язык выбирается автоматически по `initDataUnsafe.user.language_code` (`uk` → украинский, `ru` → русский, остальное → английский) и меняется в настройках. Все строки интерфейса — в `src/i18n/`.

## 6. Экраны

1. **Главный:** заголовок, общий прогресс, список уровней-карточек (номер, название, подтема, звёзды, значок хардкора), кнопка «Финальный экзамен», «Работа над ошибками (N)», «Устный экзамен», «Статистика», «Настройки».
2. **Брифинг уровня** с выбором режима.
3. **Вопрос** (три типа) → **обратная связь** с объяснением.
4. **Game over / Уровень пройден** (с итогом и кнопками «Заново», «К уровням», «Следующий уровень»).
5. **Финальный экзамен** и его итог с разбивкой по темам.
6. **Работа над ошибками.**
7. **Устный экзамен.**
8. **Статистика:** точность по уровням (простые рисованные полоски), всего ответов, лучшая серия.
9. **Настройки:** язык, тема (авто/светлая/тёмная), длительность таймера, сброс прогресса (с подтверждением), «О приложении» (`dataAsOf`, версия, ссылка на репозиторий).

Кнопка «назад» — через Telegram `BackButton`; вне Telegram — обычная кнопка в шапке. Выход из начатого уровня — с подтверждением.

## 8. Критерии готовности

- `npm run dev` открывает приложение в браузере; `npm run build` проходит без ошибок и предупреждений TypeScript; `npm test` проходит.
- Юнит-тесты движка покрывают: перемешивание без потери элементов; стартовый порядок `order` не совпадает с правильным; проверку `single`/`multi`/`order` (включая частично правильный `multi` = неверно); жизни и game over в обоих режимах; сборку финала (ровно по N вопросов на уровень, без повторов); логику списка ошибок (удаление после двух правильных подряд).
- Все 316 вопросов отображаются без обрезки текста на ширине 320 px (проверь на нескольких самых длинных вопросах).
- Прогресс сохраняется и восстанавливается после перезапуска (в браузере — через localStorage).
- В тёмной теме Telegram всё читается.
- README: запуск, деплой, привязка к боту, как редактировать вопросы, раздел «Вопросы к контенту».
